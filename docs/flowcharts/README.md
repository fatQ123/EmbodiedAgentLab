## 读图约定

- 实线箭头：真实的调用、执行或消息流。
- 虚线箭头：并行关系、观察关系或能力边界，不表示自动调用。
- 菱形：需要根据运行状态作出的判断。
- `SUCCEEDED`、`ABORTED`、`CANCELED`：ROS 2 Action 的终态。
- `OK`、`WARN`、`ERROR`：ROS 2 diagnostics 的健康等级。

## 后续更新规则

完成新的每日任务时，同时完成三件事：

1. 新增 `week03-dayNN-主题.md`，只画当天引入的核心能力及其调试分支；
2. 把当天能力接入 [`week03-overall.md`](week03-overall.md)，总图始终覆盖“第 1 天到最新完成日”；
3. 在本索引、项目 README 和对应实验记录中补上链接。

流程图以实现为准，验收状态以每日记录为准。第 4 天接入 QoS、话题停止和 TF 缺失/过期；第 5 天接入 Service 超时、Action 取消和节点崩溃；第 6 天把七个隔离场景接入自动录包、文件日志和回归报告；第 7 天固定源码提交，在干净终端重新演练并把通过的提交标记为 `v0.3`。

GitHub 的 Markdown 页面会直接渲染 Mermaid；在本地使用支持 Mermaid 的 Markdown 预览即可查看。源文件始终保留文字标签和调试命令，即使只看纯文本也能沿分支定位问题。
