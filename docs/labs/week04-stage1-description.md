## 1. 模型语义

```text
base_link
  └─ joint1（旋转）→ link1
       └─ joint2（旋转）→ link2
            └─ tool0_fixed（固定）→ tool0
```

长度使用米（m），质量使用千克（kg），角度使用弧度（rad）。零位时两连杆都沿局部 `+X`，两关节都绕局部 `+Z` 按右手规则旋转。从 `+Z` 朝原点看，正角方向为逆时针。

| 关节 | 父坐标系 → 子坐标系 | 关节 origin 在父系的位置 | 轴与限位 |
|---|---|---|---|
| `joint1` | `base_link → link1` | `(0, 0, 0)` | 局部 Z，`[-π/2, π/2]` |
| `joint2` | `link1 → link2` | `(0.4, 0, 0)` | 局部 Z，`[-π/2, π/2]` |
| `tool0_fixed` | `link2 → tool0` | `(0.3, 0, 0)` | 固定 |

所有关节 origin 的零位旋转均为零。`joint2` 的角度相对 `link1`，因此 `link2` 相对底座的朝向是 `q1+q2`。`tool0` 是工具参考点，不是额外的活动关节或夹爪。

| 连杆 | 视觉及碰撞几何 | 几何中心和质心（相对该连杆坐标系） | 假设质量 |
|---|---|---|---|
| `base_link` | 长方体 `0.12 × 0.12 × 0.04` | `(0, 0, -0.04)` | 1 kg |
| `link1` | 长方体 `0.4 × 0.05 × 0.04` | `(0.2, 0, 0)` | 1 kg |
| `link2` | 长方体 `0.3 × 0.04 × 0.03` | `(0.15, 0, 0)` | 0.75 kg |
| `tool0` | 球，半径 `0.015` | `(0, 0, 0)` | 0.05 kg |

关节 origin 确定连接位置，visual/collision origin 确定形状在连杆中的位置，inertial origin 确定质心。把连杆视觉中心放在长度一半的位置，才能使杆体从关节起点延伸到下一个关节。底座形状向负 Z 下移不会改变 `base_link` 原点，也不会给末端添加高度。

惯性基于上述均匀刚体假设计算，单位 `kg·m²`。长方体在质心处的惯量为 `Ixx=m(y²+z²)/12`、`Iyy=m(x²+z²)/12`、`Izz=m(x²+y²)/12`，球为 `Ixx=Iyy=Izz=2mr²/5`；惯性积均为零。这些质量、截面和惯性是教学参数，没有真实测量依据。关节 effort 为 `10 N·m`、velocity 为 `1 rad/s`，只是描述中的假设上限，当前链路不执行力矩或速度控制。

根连杆保留惯性信息以保持四连杆描述完整。历史运行中，`robot_state_publisher` 使用的 KDL 实际输出了不支持根连杆惯性的警告；本阶段只使用其运动学 TF，不能据此声称完成动力学验证。为保持指定坐标链，没有增加虚构的根坐标系。

## 2. 独立正运动学判据

末端相对 `base_link` 的位置与朝向为：

```text
x = 0.4 cos(q1) + 0.3 cos(q1 + q2)
y = 0.4 sin(q1) + 0.3 sin(q1 + q2)
z = 0
yaw = q1 + q2
```

下表是数学预期值，人工验收前不将其写成实际测量结果。

| `q1, q2`（rad） | 末端位置（m） | yaw（rad） |
|---|---|---|
| `0, 0` | `(0.7, 0, 0)` | `0` |
| `π/2, 0` | `(0, 0.7, 0)` | `π/2` |
| `0, π/2` | `(0.4, 0.3, 0)` | `π/2` |
| `π/2, -π/2` | `(0.3, 0.4, 0)` | `0` |
| `-π/2, 0` | `(0, -0.7, 0)` | `-π/2` |

## 3. 数据流和启动开关

```text
Xacro → URDF字符串 → robot_state_publisher
                            ↑ /joint_states
          joint_state_publisher 或 joint_state_publisher_gui
                            ↓
        /robot_description、/tf、/tf_static → RViz / 无界面观察脚本
```

活动关节变换进入 `/tf`，固定工具变换进入 `/tf_static`。机器人描述通过持久化的 `/robot_description` 提供给后来加入的订阅者。两个关节状态发布器互斥，默认每秒发布 20 次零位状态；图形界面模式由人改变位置。所有节点使用系统时间（`use_sim_time=false`）。

| 参数 | 默认值 | 含义 |
|---|---|---|
| `gui` | `false` | `false` 使用无界面发布器；`true` 使用关节滑块 |
| `rviz` | `false` | `true` 打开配套 RViz 配置 |

这些关节状态是合成的运动学输入，不是电机反馈，也不是运动命令或控制器执行证据。RViz 显示碰撞几何并不会执行碰撞检测。
