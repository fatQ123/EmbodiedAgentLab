# 系统架构（Architecture，架构）

## 当前边界

当前版本只包含 Python（编程语言）工程骨架和环境诊断工具。项目采用仿真优先路线，不要求真实机械臂：ROS 2（机器人操作系统第二代）、RViz（机器人可视化工具）、虚拟硬件、Gazebo（物理仿真器）、机械臂控制和智能体目录将在对应功能真正出现时创建。

## 目标分层

```text
任务层：自然语言目标与任务状态
  ↓
智能体层：规划、工具选择、诊断与恢复
  ↓
技能层：执行、验证、回滚与结构化结果
  ↓
机器人中间件层：ROS 2 通信、坐标变换、诊断与数据包
  ↓
规划与控制层：MoveIt 2 运动规划、ros2_control 机器人控制
  ↓
仿真层：Gazebo 物理仿真器、虚拟传感器、机械臂与夹爪
  ↓ 可选硬件适配器（第 1.0 版以后）
真实硬件层：真实传感器、机械臂与夹爪
```

## 核心设计原则

1. 智能体不直接发布底层话题，只能调用有契约的技能。
2. 技能必须返回结构化结果，并提供验证、超时与安全回滚。
3. 每次执行都形成 Episode（实验回合），保存任务、动作、证据和结果。
4. 故障恢复必须记录证据和规则，不允许隐藏失败或无限重试。
5. 学习型技能和经典技能使用相同接口与评测场景，保证对比公平。
6. 第 1.0 版的验收全部可以在仿真中完成；真实硬件适配不得改变上层技能与智能体接口。
